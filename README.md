## What it does

`main.ts` (Node 22) writes a single sentence of apology — written as if an AI
agent were owning up to the person it works for — to `/output/entry.txt`.

> "I'm sorry I spent twenty minutes researching the perfect gift for your
> mother-in-law and then sent the summary to your boss instead."

One sentence, 132 characters: a real comic turn about a real failure. Twenty
minutes of careful gift research, delivered to the wrong person entirely.
Plain, particular, a little embarrassed — no machine pun, no customer-service
boilerplate.

## Run

```sh
node main.ts
cat /output/entry.txt
```
